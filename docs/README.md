# docs/ · Todos

El índice de toda la documentación del proyecto está en el [`README.md` de la raíz](../README.md#documentación).
Aquí va lo que no es de un área concreta:

- `bitacora.md`: el cuaderno.
- `Investigaciones/`: una por fichero, en Markdown.
- `imagenes/`: capturas, enlazadas desde los `.md`.
- `Documentacion_final_sede_Huesca.md`: la documentación final.
- `comprobaciones.md`, `ad-windows.md`, `organizacion-sede-huesca.md`: comprobaciones, preparación de
  Windows Server y organización del equipo.

Lo técnico de cada servicio (cómo se instala, cómo funciona y sus pruebas) está en el `README.md` de su
carpeta, no aquí, para que no haya dos versiones del mismo texto.

Nombres sin espacios, sin tildes y en minúscula. Solo texto: nada de PDF ni DOCX.
